[5] display : flex , 하위 요소들의 배치 방법
    1) flex-warp :  
        - nowrap ( 기본값 ) 하위요소들의 크기가 부모요소보다 커지면 자동 크기 맞춤
        - wrap : 하위요소들의 크기가 부모보다 커지면 자동 줄바꿈 처리
    2) flex-direction
        - row(기본값) 하위요소 가로배치
        - column 하위요소 세로배치
    3) justify-content 
        - flex-start : 왼쪽 정렬 , flex-end : 오른쪽 정렬 , center : 가운데 정렬
        - space-between : 양쪽 ( *끝 여백없이 ) 사이 여백  균등 정렬
        - space-evenly : 양쪽 ( *전체 여백 ) 균등 정렬
    4) align-item : 세로 정렬
        - center : 가운데 정렬
        - flex-start : 위쪽 정렬, flex-end : 아래쪽 정렬
    5) gap : 하위 요소들의 간격(여백)
    
[6] 크기 단위
    1) px : 절대 크기
    2) % : (부모기준)상대 크기
    3) rem : (루트HTML)상대 크기
    4) vw/vh : (디바이스/화면) 상대 크기

[7] position
    1) static(기본값) : 정적인 위치, 위치변경 불가능
    2) relative : (본래 자신 기준)상대 위치
    3) absolute : (부모기준)절대위치, * 가장 가까운 position(static을 제외)을 사용하는 부모요소
    4) fixed : (디바이스/브라우저) 위치 고정
    5) sticky : 스크롤시 위치 고정 (특정 화면에서 벗어나면)
    * 위치변경 : left , right, top, bottom 위치 변경 가능
    * z-index : position 사용하여 요소들이 겹쳤을 때 우선 순위 *수가 높을수록

[8] 가상 클래스 / 요소
    1) 마크업:hover , 해당 마크업에 마우스를 올렸을 때
    2) 마크업::before , 해당 마크업 앞에 가상 컨텐츠 추가 (텍스트/이미지)
    3) 마크업::after , 해당 마크업 뒤에 가상 컨텐츠 추가 (텍스트/이미지)
